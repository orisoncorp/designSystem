Naming Convention
--motion-[categoria]-[variante]

Tokens são planos e categorizados pela propriedade que controlam. A camada (atom / mol / org / tpl) descreve onde um token é aplicado e vive na documentação, não no nome.

--motion-easing-enter
--motion-duration-slow
--motion-ty-base
--motion-tx-drawer
--motion-scale-max
--motion-opacity-overlay
--motion-stagger-dense
--motion-exit-ratio
easingenter · exit · state · emphasis · linear · micro
durationinstant · fast · base · moderate · slow · dramatic · cinematic
ty · txmicro · sm · md · base · lg · xl · drawer
scalemin · base · max · backdrop
opacitystart · mid · end · disabled · overlay
staggerbase · dense · dramatic · max-delay

Classes CSS seguem o padrão do próprio componente (.m-reveal, .lm-stage, .dv-kpi-card). Só tokens usam o prefixo --motion-.
