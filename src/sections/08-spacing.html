Micro --space-1 · --space-2 4px / 8px Gap entre ícone e label. Espaço entre linhas de texto pequeno. Padding interno de badges.
Componente --space-3 · --space-4 16px / 24px Padding interno de botões e cards. Gap entre elementos dentro de um componente.
Layout --space-5 · --space-6 32px / 48px Espaço entre seções de conteúdo. Margem entre grupos de elementos relacionados.
Macro --space-7 · --space-8 64px / 80px Padding de página. Separação entre seções principais. Margens externas de layout.
--space-hairline · 2px Fora da escala base 8, e de propósito. A calha de 2px é o único separador entre blocos irmãos em todo o sistema: sem raio, sem sombra, sem card. É o que faz a página ler como uma chapa escura riscada por linhas de cabelo em vez de um baralho de cartões flutuantes. Use apenas como gap entre elementos de uma mesma grade, nunca como padding.
