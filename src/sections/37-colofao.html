Quickstart

Consumir o sistema em outro projeto

O pacote expõe cada camada como um export nomeado. Importe só o que o projeto precisa — os tokens sozinhos já dão acesso a toda a escala, à paleta e ao sistema de movimento. 

npm install @orison/design-system

/* Só os tokens — obrigatório, é a base de tudo */
@import '@orison/design-system/tokens';

/* Camadas opcionais */
@import '@orison/design-system/typography';
@import '@orison/design-system/layout';
@import '@orison/design-system/components';
@import '@orison/design-system/animations';

O símbolo é distribuído como sprite SVG. Injete-o uma vez no início do <body> e referencie por <use> em qualquer lugar. 

import sprite from '@orison/design-system/symbol?raw';
document.body.insertAdjacentHTML('afterbegin', sprite);

<svg role="img" aria-label="Orison"><use href="#symbol-full"/></svg>

Regras não negociáveis

Se você quebrar uma destas, não é mais o sistema Orison
Piso de 12px

Nenhum texto abaixo de --text-label. Se a informação não cabe, ela não pertence àquele bloco.

Caixa alta é estrutura

Na rampa de texto, só em --text-label — palavra isolada ou frase curta, tracking teto 0,10em. Na rampa display é permitida em --display-hero, --display-xl e --display-sm. Prosa nunca.

Tracking em em

Nunca em pixels. 3px vale 43% do em a 7px e 9% a 32px — tracking absoluto não escala.

Crimson não é cor de texto

#8B1A1A mede 2,09:1 sobre fundo escuro. Toda tipografia crimson usa --color-crimson-text.

Sem raio, sem card

Zero border-radius em qualquer superfície — painel, bloco, campo, botão. Marcas circulares (dot de legenda, knob de switch) são marcas, não superfícies. Blocos irmãos se separam pela calha de 2px e nada mais.

Só transform e opacity

Nenhuma animação de width, height, padding ou margin. Máximo duas propriedades por transição.
