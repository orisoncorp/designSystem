Início

Como usar

Um site, um conjunto de tokens, dois temas. O tema claro é o produto; o escuro é a marca e a comunicação. Use o botão de tema no índice para ver qualquer página nos dois.

A norma

DESIGN.md é a única norma escrita. src/tokens/tokens.css é a verdade executável: se divergirem, o código vence e o documento é corrigido.

Os valores

Nenhum valor desta documentação é digitado. Cores, tamanhos e contrastes são lidos dos tokens no navegador; mudar o token muda a página.

A origem

Cada decisão veio de uma rodada aprovada (F01 a F10), com referência à pesquisa da Palantir (DR-09). O registro está em docs/fusao-palantir.md.

Consumir em outro projeto

/* tokens: obrigatório, base de tudo */
@import '@orison/design-system/tokens';
/* camadas opcionais */
@import '@orison/design-system/base';
@import '@orison/design-system/components';
@import '@orison/design-system/patterns';
@import '@orison/design-system/dataviz';

/* tema escuro num bloco ou na página inteira */
<html data-theme="dark">  ou  <div data-theme="dark">

Tokens também em JSON no formato DTCG 2025.10: npm run tokens:export gera tokens/orison.tokens.json.

Uma só cor de ação.Azul é clicável. Se algo é azul e não é clicável, está errado.
Cor é resultado.Verde, laranja e vermelho só descrevem algo que aconteceu.
Crimson é identidade.Não marca ação, erro, risco, dado nem texto.
Três eixos que não se fundem.Estado, risco e evidência nunca dividem o mesmo sinal visual.
